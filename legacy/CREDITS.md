# Credits

K3ypissr NukeBar 3.0 is a merge of two surviving branches of the HackBar
Mozilla add-on. Nearly all of the payload text, menu labels, icons and handler
logic in this repository was written by other people. This file records where
each part came from.

## Upstream add-ons

### HackBar Pro v2.9

- Archive: `vendor/pro` (XPI root, 23 files) and `vendor/pro-full` (complete
  extraction, 554 files)
- Internal id: `ph.hitachi@hackbar.com`
- Reported creator: **Ph.Hitachi**
- Version string: `v2.9`
- Role in this build: the `pro` payload pack (3,440 menu items across 168
  menus), the base XUL overlay, options window, decoder, Admin Finder,
  Reverse IP, connection/network window, `Main.js`, `SQL.js`, `admin.js`,
  `VM.js`, `Encrypt.js`, `Crypto.js`, `Toolbox.js`, `custom.js`, `update.js`

### Original HackBar

HackBar was originally published for Firefox 1.5 - 3.x by **Pedro Laguna**
with contributions from **Johan Adriaans** and, later, **farfarfar**. Several
generations of "Pro"/"Mod" forks followed. The menu structure, `hackBar`
object API (`getSelectedText`, `setSelectedText`, `Execute`, `LoadURL`,
`SplitURL`, ...) and the `HackBar.SQL` / `HackBar.admin` / `HackBar.VM`
namespaces all originate with that first add-on.

## Code and assets reused verbatim

| Path in this repo | Origin |
| --- | --- |
| `modern/content/engines/shared.js` | `namespace.js`, `Encrypt.js`, `Toolbox.js`, `Main.js` from HackBar Pro v2.9 |
| `modern/content/engines/pro.js` | `SQL.js`, `admin.js`, `VM.js` from HackBar Pro v2.9 |
| `modern/content/engines/mod.js` | `SQL.js`, `admin.js`, `VM.js`, `Strings.js`, `Main.js` from the 3xp10reX Mod |
| `modern/icons/*` | `chrome/skin/win` of both add-ons, except the app icon set |
| `assets/icon.png` | dragon mark supplied for this build; all icon sizes are derived from it |
| `legacy/src/chrome/skin/**` | both add-ons' skin trees, plus `light.css` written for this build |
| `legacy/src/defaults/preferences/prefs.js` | HackBar Pro v2.9 |

The engine bundles are generated by `tools/build-engines.mjs`, which wraps the
original files in an IIFE and replaces browser-only entry points with shims.
The payload strings themselves are untouched apart from XML escaping.

## Tools and libraries

- **LiveHTTPHeaders**, **Tamper Data**, **NoRedirect** and **View Source** were
  separate add-ons bundled inside the v2.9 archive. They are not redistributed
  here; the buttons that used to launch them now open HackBar's own network
  window. Their names appear in the legacy overlay only as historical labels.
- **Web Developer** toolbar by **Chris Pederick** inspired several of the
  original HackBar tools (form inspection, cookie editing, view source).
- Skin icons are 16x16 PNG/GIF files taken from the two add-on skins. The
  application icon (`assets/icon.png`) was supplied separately for this build;
  `tools/brand-icons.mjs` downsamples it, so no other new artwork was drawn.

## New work in this repository (2026)

Written for the combined build and licensed GPL-2.0-or-later:

- `tools/extract-payloads.mjs` - parses both `hackbar.xul` overlays and merges
  them into one source-tagged payload tree
- `tools/build-engines.mjs`, `tools/test-engines.mjs` - engine packaging and
  smoke tests
- `tools/dedupe-payloads.mjs` - renders every handler and removes rows that
  produce identical text
- `tools/brand-icons.mjs` - dependency-free PNG/ICO resizer for the icon set
- `tools/build-legacy.mjs` - rebuilds the XUL add-on, namespaces the Mod
  modules, generates the 13 Mod menus, repairs malformed handlers
- `tools/package.mjs` - assembles `dist/firefox`, `dist/chrome`
- `modern/background.js`, `modern/content/shims.js`, `modern/content/app.js`,
  `modern/content/panel.js`, `modern/content/panel.css`
- `modern/pages/*` - popup, options, about, poster, viewer, decoder,
  Admin Finder, Reverse IP, network viewer
- `modern/manifest.json`, `modern/manifest.chrome.json`
- `legacy/src/chrome/skin/*/css/light.css`, the rebuilt `install.rdf`,
  `chrome.manifest`, `ModSQL.js`, `ModAdmin.js`, `ModVM.js`, `Strings.js`,
  `java.js`
