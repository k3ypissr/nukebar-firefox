K3ypissr NukeBar 3.0

Modern Firefox-inspired interface with the full HackBar v2.9 payload set, rebuilt for current Firefox and Chromium browsers.

This build merges the two surviving HackBar lineages into one extension. Menus, handlers and payload text come from the original add-ons; the surrounding chrome was rebuilt as a standard WebExtension because neither legacy XPI installs on current browsers.

What is included

  • Merged SQL, WAF, UNION, LFI, XSS, encoding and tool menus (3,600+ entries)
  • Source-tagged payloads: P HackBar v2.9, M k3ypissr
  • Load URL, split URL, POST body, custom Referer and Cookie headers
  • Response viewer with sandboxed preview and header table
  • Local decoder / encoder toolkit and hash helpers
  • Admin Finder wordlist scanner, Reverse IP lookup, network viewer
  • DIOS / QUERY / XSS payload preferences and custom payloads
  • Firefox-inspired light and dark themes with rounded controls, soft shadows and smooth transitions

Execution notes

  • Firefox: real header replacement through webRequest.
  • Chromium: declarativeNetRequest session rules for Referer and Cookie.
  • POST replay uses a real form submission so cookies, redirects and history behave normally.
  • Raw bodies that are not form-encoded fall back to an extension-side fetch and the viewer.
  • Some networks (proxy, DNS, certificate) are outside what an extension may observe; the network viewer shows only what the browser exposes.

Keyboard
